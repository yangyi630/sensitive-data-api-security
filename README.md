# 敏感数据加密与接口安全防护开发

## 项目简介

本项目是一个信息安全专业课设，实现了敏感数据加密与接口安全防护的完整解决方案，包含：

- 敏感数据AES-256-GCM字段级加密
- JWT认证与Refresh Token轮换
- 防重放攻击（Nonce + Timestamp）
- 接口限流保护
- CSRF防护
- 数据脱敏
- 安全HTTP头
- 可视化安全仪表板

## 技术栈

- **后端**：Python 3.10+ + FastAPI
- **数据库**：SQLite + SQLAlchemy 2.0
- **缓存**：Redis（支持fakeredis回退）
- **前端**：纯原生HTML/CSS/JS + Chart.js
- **部署**：Uvicorn

## 核心功能

### 1. 敏感数据加密
- 密码使用bcrypt哈希
- 敏感字段（手机号、身份证、银行卡）使用AES-256-GCM加密
- 支持密钥轮换

### 2. 接口安全防护
- JWT认证（15分钟access token，7天refresh token）
- Refresh Token轮换防止重用攻击
- 防重放攻击（Nonce + Timestamp）
- 接口限流（100次/分钟通用，5次/分钟敏感接口）
- CSRF双重提交Cookie防护
- 安全HTTP头

### 3. 可视化界面
- 加密工坊：加密/解密演示
- 脱敏秀：用户数据脱敏展示
- 攻击防御动画：重放攻击、限流、CSRF测试
- 安全态势仪表：实时安全状态
- 审计日志流：安全事件记录

## 安全特性

- **SQL注入防护**：使用SQLAlchemy ORM参数化查询
- **XSS防护**：输出编码和CSP策略
- **敏感数据保护**：自动脱敏和加密

## 常见问题解决

### 问题1：端口被占用

如果启动时出现端口被占用的错误：
```
[Errno 10048] error while attempting to bind on address ('127.0.0.1', 8006): [winerror 10048] 通常每个套接字地址(协议/网络地址/端口)只允许使用一次。
```

**解决方法**：使用其他端口，例如：
```bash
python -m uvicorn main:app --host 127.0.0.1 --port 8007
```

### 问题2：依赖安装失败

如果安装依赖时出现网络错误：

**解决方法**：使用国内镜像源：
```bash
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### 问题3：登录失败

如果登录时出现错误：
- 确保输入了用户名和密码
- 检查服务器是否在端口8006上运行
- 刷新浏览器后重新尝试

### 问题4：加密功能无法使用

- 确保已经登录成功
- 检查JWT状态是否显示"已登录"
- 刷新页面后重新尝试
